# Como executar o projeto

Para tentar deixar o setup mais simples, eu coloquei tudo em docker, assim você instala apenas uma ferramenta, em vez de várias diferentes pro ambiente todo funcionar, então vamos ao passo a passo:

1. Instalar o docker caso ainda não tenha instalado

-   [doc oficial windows](https://docs.docker.com/desktop/setup/install/windows-install/)
-   [doc oficial mac](https://docs.docker.com/desktop/setup/install/mac-install/)
-   [doc oficial linux](https://docs.docker.com/desktop/setup/install/linux/)

2. Navegue até o diretório raiz desse projeto

3. Levantar todo o ambiente com docker compose usando o comando a seguir:
```
docker compose up -d
```
